# Razorpay Clone

This project is a clone of the Razorpay website, showcasing its design and features. It is built using HTML, CSS, and JavaScript, with Tailwind CSS for styling.

## Features

- **Responsive Design**: The website is fully responsive and adapts to different screen sizes.
- **Hero Section**: A visually appealing hero section with a call-to-action button.
- **Feature Sections**: Highlighting key features of Razorpay, such as payment solutions, business banking, and more.
- **Core Features**: Detailed descriptions of Razorpay's core features, including instant activation, easy integration, and secure payment modes.
- **Testimonial Section**: Showcasing customer testimonials.
- **Call to Action**: Encouraging users to sign up and explore Razorpay's offerings.
- **Footer**: Informative footer with company details and newsletter subscription.

## Project Structure

```
Index.html          # Main HTML file
style.css           # Custom CSS for additional styling
tailwind.config.js  # Tailwind CSS configuration
postcss.config.js   # PostCSS configuration
package.json        # Project dependencies and scripts
image/              # Folder containing all images and icons
```

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling the website.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
- **JavaScript**: For interactive elements.

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd Razorpay
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start script:
   ```bash
   npm run start
   ```
5. Start a local server to view the project in your browser. You can use extensions like Live Server in VS Code.

## Folder Structure

- **Index.html**: The main HTML file containing the structure of the website.
- **style.css**: Custom CSS for additional styling.
- **tailwind.config.js**: Configuration file for Tailwind CSS.
- **postcss.config.js**: Configuration file for PostCSS.
- **package.json**: Contains project dependencies and scripts.
- **image/**: Contains all images and icons used in the project.
